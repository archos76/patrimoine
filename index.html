Prélèvements sur les dividendes
Ce que l’État retient au moment où le dividende est versé. Sur un compte-titres c’est 30 % (le prélèvement forfaitaire unique). Dans un PEA ou une assurance-vie, rien n’est retenu tant que tu ne retires pas : laisse 0. Change un taux si ta situation diffère, par exemple pour une retenue étrangère.

Sécurité et clés
Cette application est une page publique : n'importe qui peut en lire le code source. Rien de ce qui est écrit dans le fichier n'est secret. Tes données, elles, sont dans ta base Google et protégées par les règles de sécurité de celle-ci — pas par le code de la page.
Clé Alpha Vantage (comparaison au S&P 500)—
Elle est enregistrée dans tes données, pas dans le fichier. Sans clé, tout fonctionne : seule la colonne S&P du Panorama reste vide.
Vérifier que mes données sont bien protégées
Va sur console.firebase.google.com, choisis ton projet, puis Firestore Database et l'onglet Règles. Tu dois y lire quelque chose qui limite l'accès à ton propre compte. Si tu vois allow read, write: if true, ou une date d'expiration passée, tes données sont ouvertes à qui connaît l'adresse de ta base. Les règles qui conviennent à cette app : 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null
                         && request.auth.uid == uid;
    }
  }
}
Avec ça, seul toi, une fois connecté avec ton compte Google, peux lire et écrire tes données.
